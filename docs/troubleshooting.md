## 트러블슈팅: Security Group 설명 문자 오류

| 단계 | 내용 |
| --- | --- |
| 증상 | `plan`에서 SSH 규칙 설명 오류가 발생했고, 규칙 수정 후 `apply`에서도 그룹 설명 오류로 중단됐다. |
| 가설 | 규칙과 그룹 설명에 AWS가 허용하지 않는 문자가 포함됐다. |
| 검증 | 두 설명의 `learner's`에 포함된 작은따옴표가 허용 문자에 포함되지 않음을 확인했다. |
| 조치 | 규칙 설명을 `SSH from the learner IPv4 /32`, 그룹 설명을 `Public HTTP and SSH from one learner IPv4 address.`로 수정했다. |
| 결과 | 최초 실패에서 6개 리소스가 부분 생성됐다. 상태를 보존하고 설명 수정 후 재배포하여 8개 리소스 생성과 웹 응답을 확인했다. |
| 재발 방지 | 그룹·규칙 설명을 함께 점검한다. 부분 실패 시 state를 보존하고 새 plan을 검토한다. |
